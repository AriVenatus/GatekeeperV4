# Production deployment log (Hetzner, `fullsendhub.de`)

First real-world deployment of this fork, done 2026-08-06/07. Standalone systemd service (not an AMP-managed instance), dedicated non-root Linux user, full feature set (`perms_super()`, no `-whitelist-only`). Layout: `/opt/gatekeeper/app` (this repo, `git pull`-updated), `/opt/gatekeeper/venv` (deliberately outside the systemd unit's `ReadWritePaths`, so the running service can never write its own dependencies), secrets in `/opt/gatekeeper/gatekeeper.env` (systemd `EnvironmentFile=`, `chmod 600 root:root`, kept outside the repo checkout entirely). Server runs **Python 3.13**. AMP account: `Gatekeeper-Bot`. First discovered instance: `Minecraft-test01`.

The full debugging/fix narrative from getting this deployment working (Python 3.13 compatibility fixes, AMP request-shape/header fixes, the Super-Admin bootstrap root-cause fix, permission-node cleanup, `requests.Session()` reuse, secrets hardening) is summarized in [`changelog.md`](/docs/changelog.md)'s "Update 4.9.0" entry. This file keeps only what's still operationally relevant to this specific server.
